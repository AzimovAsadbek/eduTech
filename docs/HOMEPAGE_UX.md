# Homepage UX Architecture

Story arc: **ENTRY → DISCOVERY → TRUST → EXPLORATION → PROOF → (world shift) → MEDIA → CONVERSION**

| # | Section | Goal | Signature interaction |
|---|---|---|---|
| 0 | Header | Orientation, always-available CTA | transparent → glass → compact on scroll; inverts on dark sections |
| 1 | Hero — "Kelajak kasblarini bugundan oʻrganing." | Immediate positioning + energy | Word-stagger headline, ecosystem composition (code / AI / robotics / camera / reel tiles) orbiting a photo slot, glass stat chips, cursor parallax |
| 2 | Direction ticker | Show breadth in one glance | Slow marquee of 9 directions, pauses on hover |
| 3 | Journey — "Bilimdan koʻnikmaga. Koʻnikmadan kasbga." | Explain the education model | Pinned on desktop: progress rail fills while 01 Learn → 04 Grow steps swap in; vertical timeline on mobile |
| 4 | Courses index | Exploration, outcome-driven | Editorial index rows (No. · Course · Role · Duration · Level) with cursor-following preview card; category filters; row → `/kurslar/[slug]` |
| 5 | Why EduTech — manifesto | Trust | Large statements reveal line by line; highlighted words; proof strip (real photos when available) |
| 6 | Results — "Bizning natijalarimiz gapiradi." | Proof | Counters (500+ / 9+ / 100+), student story cards in a draggable horizontal rail; hidden when no real stories |
| 7 | World shift EDU → MEDIA | Storytelling transition | Scroll-driven curtain: background darkens, wordmark morphs "EDU" → "MEDIA" |
| 8 | Media hero — "Brendingizni kontent orqali koʻrsating." | Second positioning | Cinematic dark, orange light leak, CTA pair |
| 9 | Service explorer | Understand offerings | Split panel: service list ↔ live detail with attributes (Creative · Fast · Vertical · Conversion); accordion on mobile |
| 10 | Portfolio preview — "Biz yaratgan kontentlar." | Proof for media | Editorial masonry with hover play; hidden when no real projects |
| 11 | Application — conversion | Convert | Two-path form (Edu / Media) on peach ambient with glass card; contact facts + map |
| 12 | Footer | Navigation, trust | Giant wordmark, branches, hours, socials |

Every section answers: purpose · hierarchy · interaction · identity. Sections that need real assets degrade gracefully (hidden or replaced with a structural placeholder in demo seed).
